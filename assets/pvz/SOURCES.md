# Plants vs. Zombies artwork sources

These are third-party Plants vs. Zombies game assets for a non-official classroom
2048 theme. Character names and original game artwork belong to PopCap / EA.
The original 2048 code license does not grant a license to these game assets.

Downloaded on 2026-11-02. Images are stored locally so the game does not depend
on third-party image servers at runtime. No executable code was downloaded.
